# MS-Excel---Financial-Dashboard
Financial Dashboard Summary

This Excel dashboard presents a financial analysis of credit card customers. It provides an overview of card categories, annual fees, credit limits, transaction amounts, transaction volume, revolving balances, customer acquisition costs, interest earned, and delinquent accounts.

The dashboard also helps analyze customer spending based on transaction type, expenditure category, card usage method, and utilization ratio. It gives a clear view of customer financial activity and can be used to identify spending patterns, revenue generation, and customer payment behaviour.
